这是什么

这是 OpenAI 的数据共享计划：你的组织在 API 设置里同意把调用的输入和输出共享给 OpenAI 用于改进模型，作为交换，名单内的模型每天有一笔免费 token 额度。它不是免费套餐，也不是试用金 —— 交换条件就是你的调用数据，所以敏感项目、客户数据不要走开启共享的项目。

我有没有资格

  • 组织已到达 Build 层级（累计购买过至少 $5 额度）；Launch / Grow 层级额度更高
  • 你是组织的 Owner（只有 Owner 能看到并切换共享设置）
  • 打开数据共享设置页能看到资格提示（如 “You’re eligible for free daily usage”）即代表有资格；看不到就是暂未开放
  • 账户里要有正余额，否则免费额度用不了

开启步骤

  1. 登录 platform.openai.com，建议先单独建一个测试用 Project，只让不敏感的流量走它
  2. 进入 Settings → Data controls → Sharing
  3. 打开 Share inputs and outputs with OpenAI
  4. 只有开启了共享的项目产生的流量才计入免费额度；用量页里能看到 “Data Sharing Incentive” 的抵扣
  5. 随时可以回到同一页面关掉，关掉后不再共享，也不再有免费额度

额度规则与坑

  • 两个池子，各一份。旗舰池每天 100 万 token（Build 25 万），小型池每天 1,000 万 token（Build 250 万），池内所有模型共享这一份。
  • 越线整单收费。系统按当日累计判断：某次请求会让总量超过额度时，这整条请求按原价计费，不是只有超出的部分收费。
  • 每天 UTC 00:00 重置（北京 08:00 / 东京 09:00），不累计、不结转。
  • 不计入的部分：微调模型、微调训练、Evals 评测、工具调用（如联网搜索）都不走免费额度。
  • 计划可终止：OpenAI 承诺终止前提前 30 天通知。

按任务选模型

  • 通用主力 — 复杂推理、编码、多步 Agent 的默认档，拿不准就先看这组的新锐模型
  • 深度推理 — o 系列，数学、科学、法律、金融这类高难多步问题；代价是慢，且这组多数已排期关停
  • 编程专用 — 为 Codex 的 Agent 编程优化；注意本组都已关停，新项目直接用通用主力的新锐模型写代码
  • 视觉与长文 — GPT-4o 的看图与多模态、GPT-4.1 的百万上下文长文档；整组都在关停倒计时里
  • 轻量高速 — mini / nano 档，分类、抽取、排序、打标这类高量重复活，额度池还大（小型池 1,000 万/天）

常见问题

这是真免费吗？
额度内是真免费，但门槛是先到 Build 层级（买过 $5 额度）且保持正余额；交换条件是共享调用数据。
ChatGPT 的 Plus / Pro 订阅包含 API 免费额度吗？
不包含。订阅和 API 是两套账，这个计划只针对 API 组织。
为什么名单里有已经关停的模型？
官方那篇文章更新滞后，还挂着已关停的模型。本站按官方下架页给它们打了「已关停」标记，复制之前先看标记。
额度是每个模型一份吗？
不是。同一个池里的模型共用一份，旗舰池一天总共就 100 万 token。
用了工具调用（联网搜索等）还免费吗？
工具调用不计入这个计划，相关请求按正常价格收费。
